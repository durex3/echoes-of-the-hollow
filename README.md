# 空谷回响 / Echoes of the Hollow

Godot 4.7.2 + GDScript 的 2D 类银河恶魔城工程基础，使用本机《类银河恶魔城锻造坊》素材。
当前版本 **0.13.0：水闸回响·主动蒸汽防护**。共十六个可编辑房间（第一关九区、第二关七区）、两个章节终点；第一关已获用户整体试玩认可，第二关人工体验与发布验收仍待完成。
当前优先完成游戏内容；Windows 打包与浏览器兼容放到内容完成后的发布阶段。每轮照常执行开发回归，不要求先制作试玩包或等待用户试玩才能继续。

## 立即运行

1. 双击根目录 `Play.cmd` 运行；或双击 `Open-Editor.cmd` 打开编辑器，按 F6 运行当前场景、F5 运行整个项目。
2. 启动器优先使用 `E:\Godot_v4.7.2-stable_win64\Godot_v4.7.2-stable_win64_console.exe`。
3. 也可以在 Godot 项目管理器导入此目录的 `project.godot`。无需安装插件、Python 包或 .NET。
4. 双击 `Check.cmd` 运行项目规范、引擎导入、行为测试与跨进程存档检查。

命令行（在项目根目录运行）：

```powershell
.\tools\run.ps1 -Editor
.\tools\run.ps1
.\tools\check.ps1
.\tools\check.ps1 -Visual
# 换电脑后显式指定，不必修改工程：
.\tools\run.ps1 -GodotPath 'D:\Tools\Godot.exe'
```

`-Visual` 会开启短暂的测试窗口并生成 `artifacts/` 截图；普通检查不打开窗口。
开发检查需要 Python 3（仅标准库，用于静态检查）；运行游戏本身只需要 Godot。

## 当前玩法

- 地图素材统一采用《类银河恶魔城锻造坊》。第一关保留森林遗迹；第二关新增原图集砌石地面、暗墙拱洞、木板渡口、水面、动态火盆、门和箱桶，四房间分别呈现渡口、高廊、仓储石室、炉心大厅。后续关卡遵循“统一像素风格、独立区域主题”，见 [关卡美术规范](docs/art_direction.md)。

- **进入第二关**：继续旧存档，前往空谷心室；击败守门者并唤醒最终回响后，靠近最右侧新门（x=604），按交互键进入「余烬水道」。已完成第一关的旧档直接开放，不必新开游戏。
- 余烬渡口有存档祭坛和安全教学段。蒸汽喷口绿色表示停歇，琥珀色预警 1 秒，白色喷发造成 1 点伤害；等待停歇或跳过，冲刺依然不提供无敌。
- 两条支路可任意顺序：**长廊深处进入水闸井**，攀登取得流量阀印，打开下层通向档案室的双向通道；**档案室东侧进入下层泵房**，清场取得压力阀印，开放直返渡口的双向近路。领取阀印回血、保存并解释新通路，再回渡口东侧进入炉心。旧档已有阀印继续有效。
- 水闸井最高层可进入**回响秘库**，无敌人、有祭坛；通过可选二段跳路线获得**水闸回响**并回满生命，新领取不再增加生命上限。默认 **L / 手柄 LB（L1）** 开启1.5秒防护，抵挡一个喷口当前这一轮喷流，冷却从启动计5秒；不抵挡其他喷口或敌人攻击。HUD显示就绪、防护、抵挡与冷却，中英文领奖说明跟随重绑。旧档已领水道之心保留原生命加成，继续游戏时自动补发技能。主线不要求此奖励；炉心修复后蒸汽仍永久停用。
- 阀门长廊新增同一课程素材包的**飞翼宝箱怪**，替换原史莱姆：感知后预警0.7秒并锁定方向，短距离扑咬，扑空后收招0.95秒。跳过扑咬后反击，剑击也能打断；需要三次命中。台阶上有中英文教学牌。档案室新增**粉焰剑士**：先后撤，再锁向突斩，可跳跃躲避或挥剑打断。第二关不再刷第一关怪物，独立Boss尚未开发。
- 炉心入口自动记录渡口重试点并回血；完成粉焰剑士与飞翼宝箱的组合遭遇后唤醒炉心，第二关所有喷口永久停用。终点可继续探索，两章随时往返。本次没有新增第二名 Boss。
- 地图根据当前房间选择章节，通关第一关后可用地图上方按钮切换第一/第二关地图；阀印、目标、门槛和奖励提示均支持中英文。

- 主菜单或暂停菜单进入 **设置 / Settings**：分别调整音乐与音效音量、切换全屏、调整辅助选项、重绑键盘或手柄按钮。按键冲突会提示；ESC 取消捕获，暂停键 ESC / Start 保留；支持恢复默认按键。下方操作、交互与能力说明跟随当前设备和映射。
- 生命显示为数值和菱形图标；冲刺显示未解锁、就绪、恢复中与落地恢复状态。Boss 血条下显示横扫/突进/收招/换阶段提示，两种预警有不同声音。
- 地图增加三印收集清单、下一目标、目标房间标记和已知锁门条件。未探索房间名称仍隐藏。
- 新主线：取得守望者封印、墨文封印并点亮风信标后，回到森林地面靠东侧的三印门（x=1000），按 E 进入回响前庭。门上槽位显示已有印记，缺少时提示对应地点；HUD 随进度给出下一目标，两条支路可按任意顺序完成。
- 回响前庭两级台阶上的内门现已通往空谷心室。进门前回满生命并记录前庭重试检查点；首领房左侧可撤退，失败回前庭祭坛，未击败的首领会重置。
- 空谷守门者有 12 HP：琥珀色横扫预警先退开或绕后，青绿色突进预警后适时起跳，收招时挥剑反击。半血后进入第二阶段，预警时长保留；普通冲刺仍没有无敌。入口先观察，跨过地面指引后才开战。
- 击败首领会回满生命、保存唯一击败标记并解封右侧最终回响。按 E 唤醒后进入「空谷复苏」结局，可继续探索；再次访问不会刷新已击败的首领。生命之花和高台事件仍可选，旧档印记直接有效。
- 主菜单或 ESC 暂停菜单点击 **Language / 语言**，切换 English / 简体中文，立即生效并记住选择。首次默认英文，旧进度不受影响。
- 领取能力、生命之花、封印或风信标后显示独立奖励卡片：名称、效果、下一步操作和保存结果。显示 6 秒，暂停/地图期间保留阅读时间，不阻挡操作。
- A/D 或方向键移动；空格跳跃，短按跳得低，长按跳得高。
- J 挥剑；E 与附近存档点、门、能力和终点交互。
- 解锁后 K / 手柄右肩水平冲刺：0.18 秒约 112px，冷却从启动计 0.45 秒；每次落地前最多一次空中冲刺。没有无敌，不穿普通墙，不取消剑击收招。
- Q 打开/关闭房间地图，ESC 返回；地图显示当前位置、已探索房间、相邻未知区域、最近存档点和已开放的单向捷径。ESC 暂停/继续；M 静音。
- 手柄初始映射：左摇杆/方向键移动、底部按钮跳跃、左侧按钮攻击、顶部按钮交互、Start 暂停、Back 地图。界面随输入显示通用手柄按钮名称；实体手柄硬件验收待完成。
- 森林向右进入遗迹，跳上两级平台获得二段跳；返回森林，登上较高祭坛并交互完成原型。
- 森林高台祭坛右侧新增秘境入口：解锁二段跳后，按 E 跟随高处树根进入 Root Sanctuary。三级平台通向 Heart Bloom，领取后永久增加 1 点生命上限并回满生命，死亡、换房和读档后仍有效。
- 秘境地面最右侧进入 Wind Gallery（风廊），领取 Wind Echo 后按 K 撞开青绿色风障。能力和已开风障均保存，不要求先领取生命奖励。
- 穿过风廊进入 Silent Belfry（寂静钟楼），利用掩体和冲刺调整位置，击败铠甲与施法者。清场后点亮风信标，开启最右侧返回森林高台的捷径；西门随时可退回风廊。
- 遗迹最右侧按 E 进入守望者训练厅：观察台 → 单只活铠甲 → 中途存档 → 铠甲与史莱姆混合遭遇。清场后领取封印，解锁东侧返回森林的捷径。
- 活铠甲出现琥珀色预警时后退或绕到背后，等挥砍结束再反击；攻击开始后它不会立即转向追打。
- 领取训练厅封印后，向左回到混合遭遇区的新增门，看到 `E / ENTER THE INK SANCTUM` 按 E 进入墨文圣所。已有训练封印的旧档也能直接进入，无需重新清场。
- DoomScribe 紫色蓄力时锁定瞄准方向，随后发射直线墨弹；起跳或用石块掩体躲避，靠近挥剑可以打断施法。圣所后半段是活铠甲与远程敌人的组合遭遇。
- 圣所中途设有两侧掩体保护的存档点。清场领取墨文封印后，最右侧出口返回遗迹；西侧门始终可退回训练厅。
- 剑击分准备/生效/收招，只有生效阶段扣血。命中带短暂火花、闪白和轻微镜头反馈；ESC 菜单可开启 Reduce screen shake / Reduce hit flashes，设置会保存。
- 存档点恢复生命并保存；能力获取和终点也保存。死亡回到最近存档点，小怪随房间重载刷新。
- 训练厅封印也会保存；旧版存档自动迁移，保留能力、检查点和探索完成状态，无需删除旧档。
- 主菜单存在有效存档时显示 Continue；选择新游戏需确认，下次保存时覆盖原存档，取消不修改进度。

## 工程导航

```text
app/                  主入口与游戏流程接线
core/                 会话状态、纯数据存档、音频服务
features/
  player/             玩家场景、状态、动画资源、可编辑配置
  combat/             生命、攻击区、受击区可复用组件
  enemies/            两章独立敌人阵容、粉焰剑士、守门者与配置
  world/              房间、TileSet、交互点、背景、rooms/*.tscn
  ui/                 原生 Control/Container 界面
assets/               当前使用/预留的素材与来源清单
tests/                真场景/真物理集成测试，跨进程存档测试
tools/                启动、检查、首次资源整理工具
docs/                 设计、架构、流程、测试与决策记录
artifacts/            本机检查日志和截图（不提交）
```
