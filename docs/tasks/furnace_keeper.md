# 炉心监守者：第二关独立终局

目标版本0.14.0，2026-09-26。采用level-design、game-ai、create-game-assets及Godot脚本/场景/动画skill。第二关七区地形与双阀回环不改，将炉心混合小怪终点替换为独立施法首领。

## 规则与可达指标

玩家现有跑速230px/s，单跳约102px高，冲刺111.6px，均不改。裂焰伤害高38px，普通跳可躲；喷发标记宽66px，0.9s预警可步行离开至少207px，冲刺/护盾仅提供额外容错。初见入口与西侧退路安全，x610后开战。入口原蒸汽保留，开战暂时关闭炉心普通喷口，避免场外时钟叠加首领招式。

首领14HP，先1.2s入场，交替地面裂焰与锁定脚下喷发；每招0.9s预警、0.4s释放、1.8s反击窗口。受击不打断预警；半血且见过两招后进入1.2s安全转阶段，第二阶段喷发增加一个间隔120px的标记，预警与收招不缩短。无接触伤害，不强制盾或二段跳。西撤到x450外可脱战重置，死亡后渡口重试。

## 工程与素材

独立FurnaceKeeper/FurnaceConfig与原生场景；FurnaceFlame负责本次施法预警/伤害/消失，作为首领子节点释放，暂停随父节点冻结，死亡/脱战/切房取消。复用Health/Hurtbox与已有护盾伤害结果，不继承第一关首领行为。

角色使用本课程nega_pink_box（现有rose_frames），1.5倍显示与压力环强调首领身份；行为为远程节拍控制，与普通粉焰剑士后撤突斩不同。新特效来自同课程pink_box_effects.png，128px网格，逐字节复制并登记摘要。没有外部素材或伪称新的角色原图。

击败记录furnace_keeper_defeated并回血/保存，终点仍需交互修复炉心。已完成cistern_restored的旧档直接视为已通过，不撤销完成或复活首领；可选回忆挑战用于旧档体验，不能发放重复进度。schema保持2，新增白名单。自动检查不等于人工难度认可。

## 验收

原生场景/来源、双语预警/血条、两种招式真实碰撞/跳跃/离开标记/护盾、两阶段、暂停/死亡/撤退/重进、同归于尽拒绝胜利、保存失败重试及旧档通过需回归；两顺序主线通过正常输入击败首领。图形复核与实际结果记录verification.md。发布打包仍在游戏内容完成后。
