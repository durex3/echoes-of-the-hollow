# 水闸回响：可选能力奖励

日期：2026-09-26；版本：0.13.0。用户认可第二关探索后，希望奖励具有能力变化，而非再次只增加生命。

## 玩家流程

水闸井高门→回响秘库→二段跳160px高台→交互领取水闸回响与满血→双语卡片说明→在安全秘库试按→回已认识的蒸汽路线运用。新奖励不加生命上限，第一关生命花继续有效。

- 默认L / LB（L1），设置可重绑，HUD显示实际绑定、就绪、防护中、已抵挡和冷却秒数。
- 1.5秒充能；5秒冷却从启动计。成功抵挡一个喷口当前喷发，不能抵挡第二喷口、敌人或下一轮喷发。
- 不提供全局无敌；普通冲刺规则不变。暂停冻结，切房取消充能保留冷却，死亡取消、复活就绪；持按不会自动重复启动。
- 旧档已领cistern_heart保留生命加成且自动补技能；只校验后在内存迁移，下一次正常保存落盘。非法/未来存档不发技能。
- 旧设置已占用L/LB时保留旧动作，为技能自动分配空闲键，提示使用实际映射。玩家正常保存后持久化。

schema仍为2，新增稳定能力ID。旧cistern_heart保留作为历史权益，不再作为新奖励发放。测试进度和设置均隔离，涉及文件失败时沿用可恢复的祭坛重试。
