# 第三关场景制作规格与难度目标

2026-09-27。以[主设计](chapter_three.md)、[递进规范](../level_progression.md)及真实移动测量为依据。用户追加要求：**整体难度高于第二关，场景合理且有趣**。以下是九房间制作规格；阶庭/外廊/中庭/修院/回廊已形成独立前半段试玩，两种小怪与鸣石已接入。完整支路奖励、Boss和正式主线仍未接入；当前实现与规格的区别见[前半段试玩](chapter_three_preview.md)，不将设计目标写成试玩结论。

## 难度提升放在哪里

| 第二关已建立的能力 | 第三关新增决策 | 公平性边界 |
|---|---|---|
| 识别剑士/宝箱一次锁向攻击 | 杖使两种明显不同起手；前上方攻击与向下回卷要求辨认安全空间 | 不统一缩短预警，不在屏外出招，不靠加伤害制造升级 |
| 地面小怪配周期蒸汽 | 地面杖使与锁点空中掠袭，调整下一次落脚 | 最多两名活动敌人；最终组合不再叠鸣石 |
| 二段跳、冲刺的上下层探索 | 壁跃进入上层，从先前看到的断桥返回并打开新路线 | 第一次壁跃无敌人/伤害，主线不要求极限位移 |
| Boss大范围焰浪考验腾空时机 | 固定旧站位的幽魂与本体镰击先独立再组合 | 固定单屏、真实边界；贴边无安全解时禁止追加攻击 |

难度目标评价的是后半章和终局，不要求新章入口比第二关Boss更凶。保持6HP常见入场状态，但主线仍以5HP无可选盾/生命进行设计验证。可选钟庭之心让已获生命花的玩家升至7HP，不把它变成通关门票。真人验收须看首次理解、失败原因和掌握后的稳定性，不能以机器人0死亡或多受伤几次宣称“更难”。

## 九个房间的制作要求

### 1. 风蚀阶庭：从地下走向高处

- 空间：低而宽的石阶、破拱、天际断钟。入口先有连续实地和祭坛，再出现一块鸣石；不给落地即触发的出生点。
- 玩法：允许边缘踩亮后后撤看一次回鸣，再跨过；两侧都有普通地面。这里不放杖使或蝙蝠。
- 引导：向东的破拱和照亮的台阶指向外廊；西门始终明确返回炉心。
- 乐趣：先观察再主动触发机关，建立第三关的节奏语言；不是第二关蒸汽换个颜色按时喷。

### 2. 守钟外廊：认识有两种技能的精英

- 两个独立宽战斗区，中间是没有伤害的石亭；不让同一屏同时激活两名杖使。
- 首只先展示上挑，完整收招后再回卷；第二只用于练习不同起手。两区均没有鸣石、窄落脚点或空中怪。
- 长杖和整个法术必须在镜头内，敌人身后留反击空间。初稿每区宽至少384px，最终按实际法术轮廓校准。
- 清场开向中庭的门，返回阶庭不锁死。第一份成长回报是进入新枢纽，不在每个小战斗后免费回血。

### 3. 断钟中庭：认识一处地方的两种走法

- 下层有祭坛、断钟主体与两端出口，上层是两支路与中央终局桥。首屏露出低位断桥端部和向上延伸的刻槽构件，不把整座高庭强塞进571×321世界像素的可视范围。
- 修院入口在下层东侧；能力回来后从高处经过旧断钟，能辨认脚下刚走过的路。上层不用大量复制门牌，东侧承重用齿轮、另一侧用悬铃做地标。
- 两条支路的回桥回到不同侧，同一间房真实改变可走路径；最后中央桥连通，奖励能看见也能走到。
- 不在安全枢纽刷怪；支路选择无暗中难度缩放，无顺序陷阱。

### 4. 回音修院：能力必须先安全学会

- 领取台用旧跑跳可达。正式教学分为单面低墙＋宽台、两墙交替＋中继台、上出口开闩三段；下方连续实地。
- 当前可运行白盒位于`features/world/prototypes/echo_cloister_blockout.tscn`，F6启动。它验证448px连续攀升与返回路线；不是最终成品教学长度。
- 正式初学段目标每次攀升2–4次蹬墙后就有宽落脚台；较长连续壁跃留给熟练段/可选藏室。依据本轮净宽128px的实际验证布置，再测更宽/更窄的可控区间。
- 墙面刻槽统一表示可蹬，普通旧墙不自动获得能力。获得后必须通过实际攀升打开上出口，不能只凭领取标记瞬移到上层。

### 5. 承钟机室：落脚与交战分区

- 先壁跃进上层，再到宽平台面对一名杖使；不把精确壁跃和未见过的法术绑在一起。
- 第一战无机关用于热身；后段一名杖使配一块已学鸣石，让玩家选择在何处引出攻击。板外有明确避让地面，不能用机关铺满可站平台。
- 东承重在战斗结束后的安全凹室；领取一次回血并打开跨过危险区的上方桥。返回时从上面看到原来的施法场，体现探索收益。

### 6. 悬铃回廊：把天上的威胁拉到可反击高度

- 从中庭西侧进入，向西推进，门方向/出生点/地图连线统一。第一只蝙蝠出现在连续地面上，先看完整收翼与掠袭，不从屏外冲进来。
- 低位收招区域是实地，玩家能够站在身体外攻击。后段再放一只蝙蝠配一块鸣石，考验离开旧落点而非连续按跳跃。
- 西承重开另一座独立回桥；先走此支路也能独立学懂，不能依赖玩家已经走过机室。

### 7. 静声藏室：可选高精度、明确生命收益

- 入口看得到生命纹章与较难的上行路线；主线门不设在这里。
- 壁跃→二段跳修正落点→一次空中冲刺作为组合目标，原型测量后再定平台。每段失足回安全下层，不直接扣命。
- 终点钟庭之心永久+1生命上限、回血一次；领取后打开直接下行返回口，避免用重复攀登惩罚已经完成挑战的玩家。

### 8. 合鸣桥廊：唯一的两敌综合题

- 两承重释放后中庭中央桥才实体连通。前段一名杖使与一只蝙蝠，后段安全祭坛，再接Boss入口；不放鸣石。
- 用不同高度的待机位置和错开的初次起手让玩家有观察顺序。后续各自按完整招式行动，角色可以选择先压制法师或等蝙蝠下落反击。
- 大平台内有退路，两怪不能把入口唯一落脚点同时封死。失败先查初始站位和覆盖，不靠削弱伤害或给测试角色无敌通过。

### 9. 终钟台：技能组合收束本章

- 独立固定单屏，地板完整，侧墙可壁跃；没有高处藏Boss、环境自动鸣石或随机小怪。
- 第一阶段镰击与定点幽魂分别检验；第二阶段才组合。玩家既要离开幽魂旧位置，也要避开本体正面的镰击，保留完整预警和至少1.30秒最终反击段。
- 重试从战前祭坛到门目标≤6秒，无需重打桥廊；进门只保存，不回血。战斗锁实体边界，胜利后左返右结局。

## 门和回路契约

逐门数据必须包含`source_room/door_id/target_room/spawn_id/direction/required_flags`。主路线为阶庭↔外廊↔中庭下层↔修院；修院上出口↔中庭上层；中庭上层分别双向接机室、回廊、藏室、合鸣桥；合鸣桥↔终钟台。两支路回桥是新增实际通路，不能与来路门复用同一出生点制造“捷径”假象。

上/下层门要独立名称和出生点。回桥先创建可走地形、确认两端安全，再显示开放提示。不能在玩家脚下删桥或生成夹人的门。未知房间地图仍隐藏名称；没有实现第四关时，右侧结局不冒充可用章节出口。

4. 真人比较重点：第二关掌握后，第三关是否增加新的辨认与落脚决策；失败能否理解；回到中庭是否认识方向；新能力是否确实改变路线。正式结果出来前仅称“更难的设计目标”。
