# 第三关前半段试玩：实现与验收边界

2026-09-27。用户认可分阶段推进后，本阶段交付一条可实际操作的前半段路线；这不是九房间完整章节，也不是最终难度/美术验收。

本日最新修订已按真人试玩意见加入远程钟波/地面咒印、完整命中反馈接线、踏壁组合动作与第二轮环境细化。细节见下方“真人试玩反馈后的修订”；原首轮0受伤路线数字仅作历史记录。

### 最新试玩追加：小怪按局面决策

最新贴身反击修正：杖使起手距离不足52px时使用已有内侧回扫，避免近处玩家落在上挑内弧之外却仍反复选上挑；52px外保留两式轮换，原伤害轮廓与完整前摇保持。左右贴身站定连打后均通过真实反击扣血检查，旧测试为凑命中而退到58px的走位已移除。

后续真人反馈补充：连按攻击会反复重置小怪硬直。现在所有小怪的可打断阶段首击保留受击，连续0.75秒内的有效命中不再次重置动作，正常扣血、命中反馈和死亡照常发生。杖使/铃翼受击恢复为0.18秒，取消旧“受击后额外等待完整攻击收招”的流程；若本来就在真实收招阶段，则保留该窗口。完整蓄力与锁向不变，能被快速击杀的低血敌人不获得保命无敌。下文历史“受伤必定取消法术”以本条为准，详见架构与验证记录。

用户认可比例/尖啸/踏壁修订后要求小怪更智能。本轮使用game-ai方法延伸现有FSM，以下覆盖历史“远程轮换”描述，不变更HP、伤害、原前摇/收招或五房间地图。

- 杖使在远程技能冷却时保持110–148px距离，不再一味冲进剑下；玩家离得远才追近。完成至少一次攻击及完整收招后，近身压力可触发最多0.42秒短退，3秒冷却，先确认背后有地面、无墙且未越过240px出生范围。玩家离开视线后只搜索最后位置0.65秒，然后安全返回。
- 两名杖使首轮仍分别教学钟波和咒印（空中目标不放地面咒印）；后续根据目标状态选招：站定优先咒印，移动或空中优先钟波，避免对落地目标连续三次同招。起手后不改变目标点、招式或朝向。
- 铃翼遇贴近的空中玩家会尝试水平拉开，而非继续撞过来；连续俯冲两次后，若尖啸就绪且有空间，先拉开再尖啸。每次换位最多96px/1秒、冷却3秒，锁定换位点且不持续升高。俯冲落地后的1.2秒低位反击窗口保留，准备/释放/受击时不会突然闪避。
- 铃翼使用真实身体扫掠检查俯冲与换位，中心视线通畅但身体过不去时不会盲冲。无安全退路时仍可被接近；消失在墙后的玩家不会被隔墙追击或盲发技能。
- 第一、二关同步做更基础的边缘、短时记忆和攻击距离优化，保留三章从基础读取到距离博弈再到技能应对的层次。专项检查与真实路线记录见docs/verification.md；自动通过不等于真人难度验收。

### 最新试玩追加：法师比例、铃翼尖啸与宽容踏壁

用户再次反馈法师偏小、飞行怪仍只有碰撞俯冲，以及原跳墙操作反直觉；以下新规则优先于下方历史初版记录。

- 法师Sprite由5/7调整到1.0，视觉约增大40%，使用Nearest；脚底源锚点(125,167)与世界站立点不变。身体/受击盒从20×32同步校准为28×44，底边不动；近身法术轮廓与精灵使用同一比例。独立远程法术仍保留自己的5/7比例，不增加HP/伤害。
- 铃翼新增**回声尖啸**：远处至少90px时准备1.05秒，锁定旧瞄准方向；释放三道±0.28弧度扇形声刃，180px/s、最长1.45秒，释放0.20秒、收招0.85秒、冷却4.6秒。声刃遇实体墙消失，整个扇形与该次身体接触共享去重，受伤/死亡/切房取消；玩家可以及时起跳或盾挡。接近后仍使用原来的锁点俯冲及低位反击窗口。没有堆HP、添加追踪或复用法师咒印。声刃为本项目原生像素轮廓，实体形状与绘制一致，凸分解扫掠保留内弧空区。
- **踏壁操作简化**：先靠向青绿刻槽墙，之后连续点按绑定的跳跃键；可以持续按同一横向方向，不必每次立即反向。壁跃自动向外保持最多0.50秒，碰到另一面墙后提前结束并给0.18秒接续窗口；早按缓冲0.18秒，刚离墙容错0.14秒且最多离墙24px。松开壁跃按键不再切掉这次蹬墙高度，普通跳跃长短按不变。每次按键仍只触发一次，不自动长按连跳；同墙限制、旧能力预算、受伤/菜单清理仍保留。
- 输入测试用两种起步方向分别**固定按一个方向、每20物理帧点按3帧**，均6次壁跃抬升约450px；正式五房间路线的两段竖井也取消逐墙反向输入后通过。地面单跳97.40px、二段跳194.41px、双跳加冲刺水平362.71px不变。系统容错来自input-systems方法，不改地图来迎合测试。
- 获得能力的提示、修院常驻底部提示、教学牌和旧白盒说明同步简化；绑定按键从InputMap设置读取。原始桌面素材和玩家主线存档不改。

## 新敌人和机关

### 2026-09-27 真人试玩反馈后的修订

用户指出敌人受击不明显、踏壁姿势僵硬、场景不足以及杖使只有普通攻击。前述“两个施法动作”确实都只有近身效果，不能视为完成技能型敌人；本轮按此问题修订。

- **可改变走位的远程技能**：110–220px内可起手，冷却3.8秒。钟波蓄力0.85秒后以180px/s直行，最长1.65秒，遇真实墙体消失，可以跳过或盾挡；地面咒印锁定施法开始时的真实地面位置，准备至少1.05秒后爆发0.38秒，可提前离开原位、冲刺移开、跳跃或盾挡。均1伤害、受剑击打断、不追踪新位置。第一杖使先出钟波，第二杖使先出地面咒印，让分开的两场遭遇分别教学；此后远程招式轮换，近身原两式保留。
- **资源与判定**：不是新增来源不明特效。直接复用已核验Evil Wizard 2的Attack2第5帧/Attack1第4帧中独立魔法选区，5/7倍率配1.4镜头，保持1倍内部源像素。地面危险实体约59px高；准备只显示局部咒印，不预画未来攻击框。形状来自相同源帧，钟波凸分解扫掠先统一检查世界阻挡，再查询玩家；保留弯月内侧空隙。与本次身体接触共享命中去重；受伤、死亡和切房均清除法术。
- **命中表现**：试玩补接已有CombatFeedback，玩家真实剑击触发火花、命中音与小幅镜头反馈，敌人命中玩家不重复播放受伤音。杖使和铃翼受伤播放原图hurt并短闪0.10秒；减少闪烁/震动设置有效，切房清除残留效果。
- **踏壁动作**：原主角图没有专门攀墙序列。新增wall_slide（26/27）与wall_push（29/24/26）两个组合片段，贴墙朝向墙面，蹬离朝向外侧，0.22秒后回到原空中动作；墙面接触与蹬离有短暂石屑。没有改主角身份、认可的攻击帧、运动数值或物理节点。该方案是现有空中姿势的组合，仍需真人判断自然程度，不宣称补出了原素材不存在的完整攀爬动画。
- **地图第二轮**：远景堡垒使用原课程纹理替换重复方块符号；中庭增加承钟塔墙与窗龛、修院增加分层内墙、外廊增加扶壁/低墙、悬廊增加梁架，加入落地碎石与植被，钟体增加铸造纹理和铜绿。仅调整背景与装饰，五房间原生TileMap、平台和通路均保留。地图并非最终美术验收，完整章节仍未完成。

本轮使用game-feel的事件反馈方法、godot-animation的原生SpriteFrames方法、game-ai的FSM/承诺式施法方法及create-game-assets的原图审查/实际游戏尺度检查，不引入新框架。

- **BellInvoker / 暗影杖使**：4HP，1伤害；走近、锁向准备、释放、完整收招；两种起手轮流出现。所有帧由同一物理时钟定位，受实际剑击打断，身体也有真实接触伤害。Evil Wizard 2原PNG逐字节复制，250格、脚底(125,167)、Sprite 5/7 × 镜头1.4 = 内部1倍源像素。
- **动画核验后的校准**：Attack1 0–2准备、3–5实心法术伤害，第6帧已散成碎线，保留其播放但取消伤害，7收势；Attack2 0–3准备、4–6伤害、7收势。配置初稿中“3–6都伤害”已按原图修正，不因自动路线通不过调整敌人数值。
- **BellSkimmer / 铃翼掠食者**：2HP，1伤害；收翼0.9秒时锁定旧站位，以260px/s斜向掠袭，最长0.45秒，之后低位停留1.2秒。目标移动不改已锁方向；原图8–9释放、10结束。死亡先失控落下，到真实地面才播放尸体动画。87格，Sprite 10/7 × 镜头1.4 = 内部2倍源像素。
- **鸣石**：踩踏触发0.9秒无害预警，0.3秒实体石齿，1.4秒冷却。离开后才能重新踩压；持续站立不会自动无限触发。画出的四个石齿分别对应实际三角碰撞，并共享一次攻击去重。
- **BellFrameStrike**：针对当前源帧进行同步形状查询；凹轮廓分解成凸多边形，避免填满月牙中间的空区。镜像只改变局部攻击形状和精灵，不挪动物理身体。World射线阻隔薄墙；身体和法术/扑击共享该招命中列表，盾挡住后不会由另一个形状补伤，下一招单独重置。
- 原图、12张正式PNG、2份许可/来源记录进入 `assets/manifest.json`。Bat许可说明明确来自此前核验的作者页，并非伪造包内许可。Bringer原包仍在下载区，Boss动画/玩法待下一阶段正式接入。

## 检查与已知边界

`tests/bell_court_suite.gd` 分开记录组件隔离摆位与连续 InputMap 路线；默认和5HP无盾各跑一次。覆盖真实双向法术命中、透明边缘、打断、身体伤害、护盾共享去重、下一招、薄墙、暂停、死亡、鸣石平台、能力领取、短壁跃、实体开闩、双向门、重试与无主线存档写入。图形模式另拍双方向/双法术、蝙蝠阶段、鸣石及五个房间。

首轮路线76.98秒、0死亡/2受伤：自动走位一直保持112px，令法师把玩家逼到入口。查看位置后修正机器人：空闲时接近到70px引招，再在准备期间后撤，收招靠近。角色、敌人HP/伤害/预警均未因此削弱。修正后51.93秒、0死亡/0受伤、6次壁跃；这是读取敌人状态的自动路线，不代表首次真人难度。

开发中还修正了凹轮廓直接交给凸形状的引擎警告，以及装饰绘图调用参数顺序错误。失败和最终通过日志保留在 `artifacts/`，不将带脚本错误但计数为0的中途运行作为验收。

最终执行命令和结果见[验证记录](../verification.md)。尚未交付：承钟双分支及实际回桥、可选生命奖励、合鸣双怪战、镰刀/幽魂Boss、正式章节入口/存档/地图/双语接线、完整三章路线。难度高于第二关的目标主要在后半章组合与终局，本次前半段不能单独证明该目标已达成。
