# 缚钟守望者重设计方案

日期：2026-09-29  
状态：**设计提案 - 待用户审核**  
依据：`AGENTS.md`、`architecture.md`、`development_lessons.md`、`level_progression.md`

## 当前问题诊断

### 核心问题：机制复杂但决策浅薄

当前实现（bell_warden.gd）：
- 记忆回响：记录3-4个旧位置，延迟爆发 → 玩家只需"别站原地"
- 逆相残像：Boss与残像交换 → 玩家只需"远离残像"
- 断钟坠落：锁定地面 → 玩家只需"跑出圈"

**问题本质**：所有机制都是"看到危险→离开"的单一决策，缺少第二关"判断落点→选平台→起跳时机"的多层决策。

### 与前两关对比

| 维度 | 第一关 | 第二关 | 第三关当前 | 差距 |
|------|--------|--------|-----------|------|
| 核心压迫 | 7把追踪飞剑持续威胁 | 2.2秒升空蓄力+全屏火墙 | 多个延迟危险区 | **缺少持续压迫感** |
| 阶段质变 | 无剑庭→召唤剑庭 | 收招-15%+速度提升 | 危险区3→4个 | **量变非质变** |
| 能力绑定 | 冲刺躲剑 | 护盾挡火有用 | 壁跃可选 | **新能力未强制使用** |
| 反击设计 | 剑庭间隙+收招 | 落地后固定收招 | 随机失衡1.35秒 | **技巧变运气** |

### 关键失误：伪忆失衡的触发条件

```gdscript
func _clear_ghost_on_scythe():
    var toward := (ghost.global_position.x - global_position.x) * facing
    if toward >= -12.0 and toward <= 112.0 and absf(ghost.global_position.y - global_position.y) <= 58.0:
        ghost.dispel()
        staggered_by_ghost = true
        _enter(State.STAGGER)  # 1.35秒失衡
```

**问题**：残像位置是系统计算的`center.x + ghost_side * 82.0`，玩家无法精确诱导Boss攻击方向命中它。这是**被动运气**，不是主动技巧。

### 壁跃能力未被利用

第三关核心能力是壁跃，但Boss房设计为"完整地板+指定侧墙"，文档明确说"每一招仍有普通跑跳可行解"。**新能力在最终战变成了可选项**。

## 重设计方案：回响狩猎（Echo Hunter）

### 设计理念

**从"被动躲避延迟危险"改为"主动布置陷阱+预判瞬移"**

核心循环：
1. Boss记录玩家位置作为"回响锚点"
2. Boss每次攻击后可能瞬移回某个锚点继续追击
3. 玩家必须：在记录时故意站安全位置 + 战斗时预判Boss会回哪个锚点
4. 失衡窗口：诱导Boss瞬回到"陷阱锚点"（墙角/高台边缘），利用其硬直反击

## 阶段一：镰刃狩猎（学习基础）

**目标**：教会玩家Boss的攻击节奏和移动模式，建立"保持距离+收招反击"的基础认知。

### 招式组

| 招式 | 准备 | 生效 | 收招 | 玩家应对 |
|------|------|------|------|---------|
| 横扫 | 0.82秒 | 0.18秒 | 0.92秒 | 后撤或绕后 |
| 突进 | 0.96秒 | 0.42秒 | 1.10秒 | 起跳或侧闪 |
| 步行追击 | - | - | - | 保持92px距离 |

### 行为逻辑

```
CHASE状态：
- 距离 > 92px：步行接近（72px/s）
- 距离 ≤ 92px：横扫
- 连续两次横扫后：突进

攻击间隔：0.48秒
血量：18 HP
伤害：1
```

### 视觉标识

- Idle：持镰站立，紫色外袍
- 预警：抬镰（横扫）/后撤蓄力（突进），武器泛白光
- 移动：walk cycle 8帧，脚步有金属回响音效

### 验收标准

- [ ] 横扫前摇0.82秒内玩家可移动到身后
- [ ] 突进预警0.96秒足够玩家起跳
- [ ] 收招窗口可完成1次剑击
- [ ] 5HP无护盾可通过阶段一（容错约6次失误）

## 阶段二：回响烙印（引入核心机制）

**目标**：引入"回响锚点"机制，玩家需要在记录时控制站位，战斗时预判瞬移。

### 新增：回响烙印循环

**触发条件**：半血（≤9 HP）后，每完成3次普通攻击触发一次。

**完整流程**：

```
1. 【烙印仪式】0.85秒
   - Boss停止移动，举起镰刀
   - 全身泛紫光，周围出现3个空白印记框（间隔0.36秒依次出现）
   - 音效：低沉钟鸣 × 3

2. 【记录锚点】3 × 0.36秒 = 1.08秒
   - 每0.36秒记录一次玩家当前位置
   - 在该位置生成"回响锚点"（玩家残影剪影 + 紫色光圈）
   - 锚点持续存在直到下一次烙印

3. 【恢复战斗】
   - Boss恢复横扫/突进攻击
   - 接触伤害提升为2

4. 【瞬移追击】每次攻击收招后
   - 40%概率：瞬移回最近的锚点位置
   - 瞬移动画：紫色残影消失→锚点闪烁→Boss出现
   - 瞬移后0.3秒硬直，然后立即开始下一次攻击预警
```

### 玩家决策链

**记录阶段（主动布置）**：
1. 看到烙印仪式→识别即将记录3次
2. 快速移动到"安全锚点位置"：
   - 场地中央开阔区（容易反应）
   - 避免墙角（被瞬回后无退路）
   - 避免平台边缘（容易被挤下）

**战斗阶段（预判应对）**：
1. 攻击Boss时记住"哪些锚点在哪"
2. Boss收招时预判"40%会瞬回最近锚点"
3. 如果瞬回：0.3秒硬直是反击机会
4. 如果不瞬回：按正常节奏追击

### 陷阱锚点高级技巧

**设计意图**：允许高水平玩家"故意布置陷阱锚点"。

场景：Boss在场地左侧，玩家故意在右侧墙角记录锚点。
→ Boss瞬回右墙角→撞墙→硬直延长0.5秒→玩家获得更长反击窗口。

**实现检测**：
```gdscript
func _teleport_to_anchor(anchor: Vector2):
    var old_pos := global_position
    global_position = anchor
    
    # 检测瞬移后是否紧贴墙体
    var wall_check := Vector2(facing * 32.0, 0.0)
    if test_move(transform, wall_check):
        timer = 0.8  # 撞墙硬直加长
        play_sound("bell_clang")
    else:
        timer = 0.3  # 正常硬直
```

### 视觉设计

**回响锚点外观**：
- 基础：玩家记录时的动作剪影（半透明紫色）
- 边缘：旋转的符文光圈（直径50px）
- 激活前兆：Boss攻击收招时，最近锚点开始脉冲闪烁

**烙印仪式动画**：
- 0.0-0.3秒：举起镰刀，身体后仰
- 0.3-0.85秒：全身紫光由暗到亮，镰刀尖端发射3道光环扫过玩家
- 音效：深沉钟鸣递增音调

### 验收标准

- [ ] 烙印仪式0.85秒可清晰辨认
- [ ] 记录期间玩家可移动到场地另一端
- [ ] 锚点残影清晰可见，不与背景混淆
- [ ] 瞬移前有0.2秒锚点闪烁预警
- [ ] 撞墙硬直0.8秒可完成2次剑击
- [ ] 5HP可通过阶段二（记录到安全位置）

## 阶段三：钟影分裂（质变压迫）

**目标**：引入持续共存的分身，形成"交替攻击节拍"和"诱导碰撞失衡"的高级博弈。

### 新增：钟影分身

**触发条件**：≤6 HP后，进入1.2秒转阶段动画。

**分身机制**：

```
1. 【分裂】
   - 转阶段时Boss分裂出一个"钟影分身"
   - 分身外观：半透明青蓝色，同样持镰
   - 分身生命：独立6 HP，可被攻击
   - 分身始终存在，击杀后10秒重生

2. 【交替协奏】
   - 本体攻击→分身等待1.2秒→分身攻击→本体等待1.2秒
   - 形成固定节拍，玩家需要"躲本体→立即应对分身→躲分身→应对本体"

3. 【分身招式】
   - 只有横扫和短距突进（速度200px/s，行程120px）
   - 伤害1（低于本体的2）
   - 预警时间缩短20%（横扫0.65秒，突进0.77秒）

4. 【诱导碰撞失衡】
   - 如果本体攻击命中分身，或分身攻击命中本体：
     * 两者同时进入2.0秒失衡状态
     * 本体显示为金色（易伤标记）
     * 此期间对本体伤害×1.5
```

### 玩家决策链（最复杂）

**阶段三完整循环**：

```
1. Boss进入烙印仪式（0.85秒）
   ↓ 玩家：快速布置3个锚点位置
   
2. 记录3个锚点（1.08秒）
   ↓ 玩家：规划好站位，避开危险区
   
3. 本体攻击（横扫/突进）
   ↓ 玩家：躲避，记住是否瞬移回锚点
   
4. 本体收招0.9秒
   ↓ 玩家选择：
      A) 安全反击本体
      B) 等待分身攻击（1.2秒后）
      
5. 分身攻击（横扫/突进）
   ↓ 玩家：躲避，同时观察本体位置
   
6. 【关键时刻】分身收招0.7秒
   ↓ 玩家高级技巧：
      - 诱导分身站到本体攻击路径上
      - 利用壁跃快速换位，让本体下一次攻击打中分身
      - 成功→双失衡2.0秒→易伤×1.5输出窗口
      
7. 回到步骤3，循环3次后重新烙印
```

### 壁跃的必要性

**为什么阶段三必须用壁跃**：

场景1：分身在左侧低处，本体在右侧准备突进
→ 玩家需要快速壁跃到高处平台，让本体突进路径经过分身
→ 不用壁跃：来不及跑到高处

场景2：双方失衡后站在场地中央
→ 玩家需要最大化输出，但2.0秒后恢复
→ 壁跃快速接近→连击→再壁跃脱离

**房间布局要求**：
```
完整地板 y=480
低平台 y=416（左右各一个，宽96px）
高平台 y=352（中央，宽128px）
两侧墙面有壁跃标记

Arena宽度：500px（x=32 到 x=532）
```

### 新增招式：钟鸣镰斩（终结技）

**触发条件**：本体≤3 HP，且分身存活时。

**流程**：
```
1. 本体和分身同时后撤到场地两端
2. 1.5秒蓄力，全身金光，镰刀高举
3. 同时向中央冲刺（400px/s）
4. 轨迹上留下持续0.4秒的金色镰痕（宽64px，贯穿全场）
5. 伤害3，可被护盾抵挡

玩家应对：
- 蓄力期间壁跃到高平台（镰痕在地面）
- 或计算时机在中央起跳（需要0.1秒精度）
```

### 关键组件

**1. EchoAnchor（回响锚点）**

```gdscript
class_name EchoAnchor
extends Node2D

@export var player_texture: Texture2D  # 记录时的玩家帧
@export var player_flip: bool
@export var anchor_id: int
var age := 0.0
var is_active := true

func _draw():
    # 玩家剪影（半透明紫色）
    var silhouette_color := Color(0.6, 0.4, 0.85, 0.65)
    draw_set_transform(Vector2.ZERO, 0.0, Vector2(-1.0, 1.0) if player_flip else Vector2.ONE)
    draw_texture(player_texture, -player_texture.get_size() * 0.5, silhouette_color)
    draw_set_transform(Vector2.ZERO)
    
    # 符文光圈
    var radius := 25.0 + sin(age * 8.0) * 3.0
    draw_arc(Vector2.ZERO, radius, 0.0, TAU, 32, Color("b89fff"), 2.5)
    
    # 激活闪烁
    if is_active:
        var pulse := 0.5 + 0.5 * sin(age * 18.0)
        draw_circle(Vector2.ZERO, 8.0, Color(1.0, 0.9, 1.0, pulse * 0.6))
```

**2. BellShadow（钟影分身）**

```gdscript
class_name BellShadow
extends CharacterBody2D

signal defeated
signal attack_started(attack_type: Attack)
signal attack_finished

@export var config: BellWardenConfig
var master: BellWarden  # 引用本体
var health: HealthComponent
var state := State.IDLE
var attack := Attack.SWEEP
var timer := 0.0

func _physics_process(delta: float):
    # 与本体类似的FSM，但：
    # 1. 只有横扫和短突进
    # 2. 预警时间-20%
    # 3. 等待master攻击完成后1.2秒才开始
    
    # 碰撞检测
    if state == State.STRIKE:
        _check_collision_with_master()

func _check_collision_with_master():
    if not is_instance_valid(master):
        return
    if master.state != BellWarden.State.STRIKE:
        return
```

## 风险与备选方案

### 风险1：瞬移追击太难预判

**症状**：玩家无法记住3个锚点位置，瞬移感觉随机。

**备选**：
- 降低为2个锚点
- 瞬移前预警延长到0.5秒（锚点剧烈闪烁）
- 添加UI：锚点编号1/2/3，Boss头顶显示"将回到#2"

### 风险2：诱导碰撞太难触发

**症状**：玩家打了10分钟没触发一次碰撞失衡。

**备选**：
- 降低难度：分身攻击打中本体也算（单向）
- 增加提示：首次进入阶段三时，画面提示"诱导攻击相撞"
- 保底机制：阶段三持续3分钟后，自动进入一次失衡

### 风险3：分身导致视觉混乱

**症状**：玩家分不清谁是本体，被分身杀死觉得冤枉。

**备选**：
- 加大颜色差异：分身改为绿色
- 本体头顶始终有Boss血条
- 分身攻击伤害降为0.5（非致命）

### 风险4：战斗时间过长

**症状**：战斗超过3分钟，玩家觉得拖沓。

**备选**：
- 总HP降为16（阶段一10→6，阶段二6→4，阶段三4→0）
- 失衡倍率提升到×2.0
- 分身HP降为4
