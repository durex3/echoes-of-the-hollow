# 玩法与关卡设计

## 区域风格原则

按用户要求，每关地图有自己的主题与辨识度，但统一使用《类银河恶魔城锻造坊》像素素材。第一关以森林树根/遗迹为主，第二关以地下石堡水道/拱廊/木板渡口/火盆为主；不能仅修改房间名字或换色。具体选区、材质、比例和后续章节验收见 [关卡美术规范](art_direction.md)。0.10.1是第二关环境美术升级，不声称新增怪物、Boss或重新制作玩法路线。

## 第二关：余烬水道（0.12.0 重设计）

七房间以渡口为枢纽：长廊深入水闸井取流量阀印，水闸井下层打开档案室双向通道；档案室深入泵房取压力阀印，泵房打开渡口双向近路。水闸井高层接可选秘库，0.13.0起二段跳挑战奖励水闸回响并回血，新奖励不加生命上限。旧阀印、检查点和已获得的水道之心生命加成继续有效；旧心奖励自动补发技能。

水闸回响为可选时机能力：L/LB启动后1.5s内抵挡一个喷口，防护消耗后对该喷口当前喷发剩余时间安全，5s冷却从启动计算。其他喷口、剑击、扑咬和墨弹仍伤害玩家；普通冲刺不获得无敌。先在安全秘库阅读双语奖励和尝试按键，再返回已认识的蒸汽路段练习，最后可用于炉心组合遭遇。它不改变跳高/速度/门槛，未领取也能完成主线；炉心完成仍永久关停本章蒸汽，因此本章通关后该技能暂无蒸汽使用场景，后续关卡是否复用另行设计。

粉焰剑士使用未使用过的课程原图和独立七状态：3HP、220px视线感知、90px/s接近到105px范围、110px/s后撤0.25s、锁向预警0.7s、270px/s地面突斩0.22s、收招1s。没有接触伤害，剑击可打断，遇墙与台阶停止。初次在档案室宽地教学，泵房平台练习，炉心与宝箱形成组合；不复用第一关敌人类型。

难度先单独教学再组合，必经64px台阶保持余量，160px高差放进可选秘库。战斗间有祭坛、阀印回血、跨区回环和秘库休息段；详见level_progression.md。自动输入路线不代表真人难度递进已获认可。

第一关唤醒最终回响后，心室最右侧开启新门。余烬渡口提供祭坛、无敌人的蒸汽教学段和支路枢纽；玩家自由选择阀门长廊或水道档案室，清场领取两枚阀印，回到渡口东侧进入炉心。炉心是粉焰剑士、飞翼宝箱与蒸汽的混合遭遇；唤醒炉心结束本章并永久停用所有本章喷口，两章保留自由回访。

0.11.0：阀门长廊高台x=990新增飞翼宝箱，取代史莱姆；教学牌x=716在敌人感知外，蒸汽x=800与敌人之间有干燥等待段。宝箱3HP，170px感知（垂直差≤48px且无墙），0.7s锁向预警→245px/s扑咬0.38s→0.95s无伤收招；伤害1，触碰待机/预警/收招不扣血。跳跃越过扑咬，落地反击；剑击直接打断。遇墙/边缘停止，失去目标或玩家死亡取消攻击。普通重进刷新、清场领奖规则不变。0.12.0起档案室和炉心改用粉焰剑士＋飞翼宝箱，无第二关独立Boss。

沿用单跳实测约102px、二段跳160px高差、冲刺111.6px；必经台阶64px高差，不加入新移动能力或即死坑。喷口宽64px、高80px，绿色停歇2.4s、琥珀预警1s、白色喷发1s，伤害1。先单独观察再与平台、敌人组合；危险前有等待空间，近战尽量引到干燥地面。

支路祭坛位于入口安全地面；阀印领取回满生命，并开启对应回环近路。炉心入口自动把重试检查点设为渡口祭坛并回血。普通敌人重进会刷新，阀印与完成事件唯一；完成后的喷口不再刷新危险。存档失败保留本次会话进度，结局明确报告，可返回祭坛重试。

两条支路支持任意顺序；无可选生命之花要求。自动连续路线从合法的第一关完成存档开始，使用默认5HP、不增加能力、不传送。测试读取状态决策，因此其耗时不代表真人游玩时长。详细验收见 [第二关任务](tasks/chapter_two.md)。

## 目标与范围

目标：验证清晰、可维护的小型“遇阻 → 获取能力 → 返回旧路 → 到达终点”探索闭环。
现有角色/地形/史莱姆作为视觉基础；装饰几何和简单刀光由代码绘制。
九个房间、一个角色、三种普通敌人、一名两阶段首领、二段跳与冲刺、可选高台纪念与生命奖励；两条路线汇合到前庭，再挑战首领并唤醒最终回响。

## 路线

```mermaid

  A[森林出生 / 存档] --> B[看见高台祭坛]
  B --> C[沿地面向右 / 史莱姆]
  C --> D[东门进入遗迹]
  D --> E[普通跳跃登两级平台]
  E --> F[获得二段跳]
  F --> G[西门返回森林]
  G --> H[二段跳到高台 / 完成]
```

房间 forest / ruins 均为 1280×576；地面 y=480，32px 图块。
森林低台顶 y=384，高台顶 y=224（差 160px，普通跳不可达）；遗迹平台 y=416、352，各差 64px。
路径无能力自锁：二段跳获取处只能要求普通跳跃，必须先于高台能力门。
自动测试使用真实物理输入验证关键攀升。完整路线的发现感、难度和往返时间仍需人工试玩。

## 战斗与进度

主角初始 5 HP，领取 Heart Bloom 后永久提升为 6 HP；史莱姆 2 HP，剑击伤害 1。同一挥击对同目标最多结算一次。
史莱姆触碰伤害 1；主角受伤有 0.8s 无敌和短暂击退。史莱姆检测前方地面，不主动走出平台。
活铠甲 3 HP，追击速度 68 px/s、巡逻 30 px/s，感知半径 235px，触发攻击距离 62px。视线受墙体阻挡，巡逻/追击检查前方落脚点。
状态数量小，使用有限状态机；DoomScribe 提供远程变化，暂不需要行为树。
死亡保留本次会话已获得的能力，回最后存档点、HP 全满；换房/死亡刷新敌人。
存档点、能力、终点、两种封印和生命奖励触发写盘；退出本身不额外保存，避免承诺不存在的退出自动存档。

## 攻击时序与反馈

| 攻击 | 准备 | 生效 | 收招 | 伤害 |
|---|---|---|---|---|
| 玩家剑击 | 0.08s | 0.13s | 0.15s | 1 |
| 活铠甲挥砍 | 0.60s | 0.18s | 0.70s | 1 |

参数来源：`features/player/sword_attack.tres`、`features/enemies/armor_config.tres`。实际转移按 60Hz 物理帧量化。
玩家受伤立即取消攻击。铠甲准备/生效期固定朝向且不会被普通伤害打断，死亡除外；收招期没有伤害判定，反击可以打断收招。
命中触发 0.24s 粒子、闪白、击退和衰减镜头偏移；挥空没有命中反馈。暂停菜单可减弱震屏/闪烁；不使用全局慢动作或冻结。

## 训练支路

遗迹东端 x=1220 进入 training。训练厅尺寸 1280×576，地面 y=480，观察台 y=416（普通跳可达）。
入口存档点 x=160 → 观察指引 x=220 → 单铠甲 x=490 → 中途存档点 x=710 → 铠甲 x=920 + 史莱姆 x=1060 → 封印 x=1130 → 森林捷径 x=1220。
观察台和入口不触发铠甲进攻；指引先提示琥珀色预警，再让玩家尝试退让与收招反击。单敌之后留出休息段，再叠加接触伤害敌人。
领取封印必须当前房间敌人全部死亡。领取后保存 training_cleared 标记、恢复生命并永久开放捷径；不会自动更新检查点。
换房/死亡仍刷新敌人，封印不重复领取，已开捷径持续有效。训练支路不影响原二段跳探索终点，也不要求先获得二段跳。

## 墨文圣所：远程教学与组合

入口位于训练厅 x=1035，领取 training_cleared 后开放；保留原森林捷径与原探索闭环。西门随时退回训练厅，无需先清场。
scriptorium 房间为 1600×576，地面 y=480。路线：入口存档 x=160 → 指引 x=245 → 64px 掩体 x=320–384 → 单施法者 x=610 → 掩体 x=672–736 → 中途存档 x=775 → 掩体 x=800–864 → 铠甲 x=1100 + 施法者 x=1370 → 墨文封印 x=1470 → 返回遗迹 x=1540。

本版不添加随机掉落、装备和新能力；远程关卡的主观难度等待用户试玩反馈。

## 房间地图与高处秘境

Q（手柄 Back）打开房间关系图并暂停，Q/ESC/返回按钮关闭。地图不是传送界面；当前位置高亮，SAVE 标记最近存档房间，已探索房间显示名称，相邻未知区显示 UNEXPLORED。二段跳前不提示森林秘境；绿色箭头表示领取对应封印后开放的单向返回捷径。
森林高台 x=490、y=224 新增入口，要求 double_jump。与原祭坛 x=400 分开，返回点为高台 x=475，确保仍站在平台内。
sanctuary 为 960×576 无敌人的休息/探索房间：入口 x=110 → 存档 x=165 → 提示 x=215 → 三个平台 x=256–384 / 448–576 / 640–768 → Heart Bloom x=705、y=288。
平台顶分别 y=416、352、288，每级高差和间隙均 64px，低于已有普通跳跃指标；失足落回安全地面，可重新尝试。入口能力门检验二段跳，房内以轻量攀升作为战斗后的节奏休息。
Heart Bloom 只领取一次，设置 heart_bloom 标记、生命上限 +1、回满并保存；地图标注 +HP。死亡、换房、继续游戏仍从标记恢复上限，不叠加重复交互。西门 x=48 随时返回森林高台。
探索房间记录在会话中更新，随上述保存触发持久化；只走进新房间后直接退出，尚未保存的探索记录不保证保留。

## 空谷守门者与最终回响

前庭内门 → 进入前自动设置前庭祭坛检查点并回血/尝试保存 → 心室入口 x=96 → 指引 x=145 → 越过 x=205 唤醒守门者 → 击败 → 右侧 x=560 唤醒最终回响。首领出生 x=448，房间宽640、固定镜头、平地 y=480；西门 x=48 可随时撤退。失败后回到前庭 x=240，首领重置满血，无能力损失。

| 参数 | 第一阶段 | 第二阶段（HP ≤6，收招结束后切换） |
|---|---|---|
| HP / 伤害 | 12 / 每招1 | 共用剩余HP / 每招1 |
