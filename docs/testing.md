# 测试与验收

## 一条本地命令

```powershell
.\tools\check.ps1
# 修改地图/动画/UI 后：
.\tools\check.ps1 -Visual
```

引擎可由 `-GodotPath` 或 `GODOT_BIN` 指定，脚本强制 4.7.2。测试脚本错误、非零退出、日志 ERROR 都使检查失败。
测试运行器有超时保护，避免失败后无限挂起。图形检查按真实帧速运行，让音频线程能正常完成。

## 自动门禁

| 层次 | 内容 | 证据 |
|---|---|---|
| 静态规范 | 必备文件、UTF-8/结尾换行、资源路径、素材摘要、非法绝对路径 | static_check 输出 |
| 引擎导入 | 原生 Godot 扫描、脚本解析、场景/资源导入 | artifacts/import.log |
| 集成 | 真实主场景、角色、物理、命中、交互、存档与关卡可达 | artifacts/integration.log |
| 跨进程 | 进程 A 写档退出，进程 B 恢复并检查 | save_write.log / save_read.log |
| 图形回归 | 实际 OpenGL、原探索路线、攻击/预警/反击、训练指引、辅助菜单截图 | artifacts/visual.log、13 张 PNG |

集成测试独立 `test_<pid>.json`，结束清理；跨进程用独立 test_cross_process.json。不访问正式 progress_v1.json。
无窗口模式跳过音频播放；音频加载/退出由图形检查覆盖。自动检查无法证明听感、操作舒适度和实体手柄兼容。
部分用例会重新定位角色以隔离特定行为；关键平台攀升使用模拟输入真实运行物理，明确区分两类测试。

## 0.2.0 战斗回归

`tests/combat_suite.gd` 复用真实主场景和测试工具。无窗口共 83 项行为断言；图形共 96 项检查（同一组行为 + 13 张截图保存），不把重复执行计作不同覆盖。
覆盖剑击三阶段/动画/挥空/受伤取消、暂停长按隔离、真实边缘宽限与落地缓冲、训练门/观察台/指引、铠甲预警安全期/锁向/正面伤害/收招反击/边缘转向/墙体视线、隔墙命中拒绝、死亡关闭攻击、粒子释放、清场/封印/捷径、准确检查点复活、旧档迁移、辅助设置恢复。
混合遭遇的剑击测试给予玩家临时无敌以隔离伤害输出，并非无伤通关验收；清场后的持久化测试直接击杀刷新敌人以隔离保存逻辑。
存档用 schema 1 样本验证迁移，并用 schema 2 的 training/rest 与 training_cleared 做独立进程往返。设置写入独立 test_settings_<pid>.cfg 后清理。
图形门禁同时要求零错误、零失败、TEST_RESULT 结束标记；成功保存图片后仍须人工查看图片内容。

## 手动验收（每个里程碑必做）

- [ ] 从 New journey 开始，不使用调试传送，完成森林 → 遗迹 → 二段跳 → 森林终点。
- [ ] 快按/长按空格，边缘起跳，落地前按跳；无跳跃漏按或无限跳。
- [ ] 左右挥剑、空中挥剑、受伤打断；无同一挥击重复扣血。
- [ ] 敌人靠墙/边缘转向；死亡特效完成且不再造成伤害。
- [ ] 存档点保存，彻底退出程序，再打开 Continue；能力与出生房间一致。
- [ ] 死亡复活位置安全；反复往返门不产生重复玩家/重复信号。
- [ ] ESC 暂停/恢复，长时间停留菜单后没有误触发跳跃或攻击。
- [ ] 1280×720 与 1920×1080 窗口查看 HUD、菜单、镜头边界，无文字遮挡。
- [ ] 用实际手柄走完整条路线，确认映射/菜单焦点。
- [ ] 聆听音乐循环/换房、快速连续攻击音效、静音与恢复。
- [ ] 从遗迹东门进入训练厅，不使用传送，读提示后完成单铠甲和混合遭遇。
- [ ] 预警时退开或绕后，等待收招反击；左右攻击图像、受击和范围符合直觉。
- [ ] 中途存档后死亡回到 x=710 的休息处；清场领奖、捷径、完全退出再 Continue 正常。
- [ ] ESC 的减弱震屏/闪烁开关即时生效，重启后保留；连续战斗没有刺眼或晕动不适。

## 故障定位

先查日志的第一个 SCRIPT ERROR；后续错误常是连带问题。
碰撞失效：检查 shape、层/掩码、TileSet 物理数据和 move_and_slide 调用。
找不到资源：检查 `res://` 路径和大小写，执行重新导入，不手改 .godot 缓存。
存档不对：用独立测试档复现，保存损坏样本，不先删除玩家档来掩盖问题。
日志为本机产物，不作为代码提交；验收摘要写入 docs/verification.md。

## 导出验证

导出模板必须与 4.7.2 匹配。使用 Windows Desktop 预设打包后，独立运行 builds/windows 下的程序。
导出包至少验收：启动、新游戏、房间、攻击、保存、退出续玩；编辑器内检查通过不能替代这一步。
