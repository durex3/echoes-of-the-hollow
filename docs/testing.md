## 故障定位

先查日志的第一个 SCRIPT ERROR；后续错误常是连带问题。
碰撞失效：检查 shape、层/掩码、TileSet 物理数据和 move_and_slide 调用。
找不到资源：检查 `res://` 路径和大小写，执行重新导入，不手改 .godot 缓存。
存档不对：用独立测试档复现，保存损坏样本，不先删除玩家档来掩盖问题。
日志为本机产物，不作为代码提交；验收摘要写入 docs/verification.md。
