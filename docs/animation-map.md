以下是项目采用的美术映射，不是素材作者的官方动作定义；保留原始 PNG 和来源摘要不变。
索引从 0 开始、按行从左到右：列 = index % columns，行 = index / columns 向下取整。

## 修改后检查

0.8.0 HollowWarden 曾复用上述铠甲 SpriteFrames 并1.5倍缩放。0.8.1根据用户反馈逐帧放大复核，确认该复用映射的预警/攻击错段、死亡混入空白；此前仅凭整场截图的检查不足。Boss改用独立 `warden_frames.tres`，普通敌人的既有资源未修改。

| 守门者动作 | 实际原图索引 | 播放规则 |
|---|---|---|
| 待机/入场/转阶段 | 0–13 | 10fps循环，火焰与身体有自然微动 |
| 追击 | 24–31 | 10fps循环 |
| 预警举剑 | 34–41 | 剑从身侧抬至头上，按实际预警时长播放 |
| 生效挥砍 | 42–44 | 大剑弧向下扫，与实际伤害窗口同步 |
| 收招 | 45–48 | 回收剑并站起，按反击窗口播放 |
| 死亡 | 58–67 | 倒地与尘土，18fps非循环，不含空白帧 |

每次切换先stop再play，防止同名动画残留末帧；时长从帧数与fps推导速度，不假设所有片段同长。Sprite 使用2倍最近邻、position.y=-64；脚底仍位于角色原点，碰撞不缩放。移除额外金色冠形，保留原PNG火焰。初建工具 `tools/build_warden_frames.gd` 拒绝覆盖已有资源，日常编辑原生tres。截图46–57覆盖修正后的待机/预警/左右挥砍/倒地与结局。

修改原生 SpriteFrames 后执行 `tools/check.ps1 -Visual`，检查 `06_sword_active`、`08_armor_warning`、`09_counterattack`、`13_armor_strike`。
更改动作帧数量时同步相应播放速度计算；更改阶段时长须复测命中、方向锁定和反击窗口。
自动截图不覆盖每一帧的动态衔接；完整动作观感仍需人工试玩。
远程动作另看 `16_scribe_warning`、`17_ink_dodge`、`19_mixed_encounter`；必须同时复测锁定瞄准、受击取消与飞行碰撞。
