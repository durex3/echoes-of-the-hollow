# 第二关连续通关记录

本页保留0.14.0初版的历史方法与结果；其中粉焰小怪、低裂焰/锁点喷发及旧伤害次数不代表当前版本。当前铁盔剑士、宝箱AI、升空下砸焰浪与真实接触伤害的两条路线为69.60/71.83秒、均0死亡/4受伤，来源为玩法基线 `3ba389f` 的[最新验证记录](verification.md)。两种顺序均不依赖可选护盾/生命，Mac实机与真人难度另验。

日期：2026-09-26；版本0.14.0；Godot4.7.2；60Hz物理。第二关七房间，普通敌人是飞翼宝箱/粉焰剑士，炉心为独立首领。

## 方法

`tests/chapter_two_route.tscn` 继承第一关路线工具的 InputMap 操作、走跳/战斗和记录方法。每次先写入隔离的合法第一关完成存档，通过正式 Continue 路径启动于心室；只有这一测试前置包含已有能力和第一关完成标记，第二关开始后不传送、不改位置、不给无敌、不直接扣敌人血或写入进度。默认5HP，不带可选生命之花。

从心室实际移动到新门 → 渡口祭坛 → 等待教学蒸汽安全窗口 → 两支路按指定顺序 → 双阀门 → 炉心实际战斗 → 交互结束 → 继续探索 → 渡口祭坛 → 返回第一关。流量支路通过长廊深入水闸井，多级攀登清场取印，再走下层通道到档案室返回；压力支路穿过档案室进入泵房，走上层平台、下层蒸汽与宝箱，取印后走新近路直返渡口。所有必经64px台阶用正常跳跃实测，没有跳过新房间或关卡几何。

0.14.0路线还要求亲历炉心监守者第二阶段和锁定喷发，以正常移动、跳跃、挥剑击败首领；不领取可选护盾。测试可以读取敌人状态和喷口时钟以决定输入；因此证明可通行与流程闭环，不代表新玩家首次探索耗时或人类难度。普通行为套件则会使用传送/移除敌人隔离奖励和存档边界，与本测试用途明确区分。
