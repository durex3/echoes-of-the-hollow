# 第二关连续通关记录

日期：2026-09-25；版本0.11.0；Godot4.7.2；60Hz物理。阀门长廊已由史莱姆替换为飞翼宝箱。

## 方法

`tests/chapter_two_route.tscn` 继承第一关路线工具的 InputMap 操作、走跳/战斗和记录方法。每次先写入隔离的合法第一关完成存档，通过正式 Continue 路径启动于心室；只有这一测试前置包含已有能力和第一关完成标记，第二关开始后不传送、不改位置、不给无敌、不直接扣敌人血或写入进度。默认5HP，不带可选生命之花。

从心室实际移动到新门 → 渡口祭坛 → 等待教学蒸汽安全窗口 → 两支路按指定顺序 → 双阀门 → 炉心实际战斗 → 交互结束 → 继续探索 → 渡口祭坛 → 返回第一关。两支路均通过正式清场领奖取得阀印。阀门长廊的两级64px台阶用正常跳跃实测到达；没有跳过关卡几何。

测试可以读取敌人状态和喷口时钟以决定输入；因此证明可通行与流程闭环，不代表新玩家首次探索耗时或人类难度。普通行为套件则会使用传送/移除敌人隔离奖励和存档边界，与本测试用途明确区分。

## 人工试玩关注点

- 旧档进入后能否识别心室右侧新门，以及第一次看见蒸汽时能否理解三种状态。
- 两支路的选择是否清晰，台阶和墨弹掩体是否好读，炉心组合遭遇是否有足够反应空间。
- 第二关完成后的「永久停用喷口」奖励是否直观，中英文地图分页和返回是否顺手。
- 第一关整体用户试玩已通过；第二关主观节奏、难度和听感尚未由用户验收。
