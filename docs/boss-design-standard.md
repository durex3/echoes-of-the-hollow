# Boss 工程规范

本规范参考 `ColeW96/metroidvania-forge-tutorial` 的 `BossBattleOrchestrator`、`EnemyStateMachine`、`EnemyState` 和 `DecisionEngine` 的职责划分。参考仓库采用 MIT License。本工程保留 Godot 4.7.2、现有原生房间、战斗碰撞与存档契约，不逐字移植教程脚本或素材。

## 当前实现与迁移目标

三关已有独立 Boss 场景、各自的 Decision、共享 `BossStateMachine` / `BossAttackState` 和 `BossBattleOrchestrator`。三关各自的 `*_attack_state.gd` 负责招式的准备、生效、收招、位移、Hitbox 窗口、音画提示和结束；Boss 主脚本保留目标、追击、生命、身体接触、物理提交与特殊攻击生成物。三个 Boss 的 `.tscn` 原生保存状态机和每招子节点，编辑器可配置攻击 ID、名称与独立冷却；状态机从子节点收集状态，不再由 Boss 主脚本运行时 `new()` 创建。

三个 Boss 房原生保存 `BossBattleOrchestrator` 节点，配置相对 Boss 路径、血条名称及炉心喷口停用选项。编排器注入目标并连接觉醒、撤战、生命、命中和击败事件；Main 统一接入其命中与胜利信号，继续核验房间实例、玩家存活、唯一标记与挑战隔离，再处理奖励和存档。真实边界、门与固定镜头由既有房间组件负责；当前没有独立 Boss 音轨，沿用房间音乐。两项工程迁移已完成，第三关战斗画面与真人难度留待用户验收。

三关不使用按血量划分的第一、第二、第三阶段，也不在 Boss 血条显示阶段编号。招式按距离、高度、上次攻击与冷却选择；受伤不打断已开始的攻击和收招。第三关在横扫和突进之外，新增独立的双重回响与楼层共振；旧配置中尚存的实验字段不构成玩法承诺。

第二关进一步参照教程 `nega_pink_box` 的决策与技能：完成开场招式教学后，累计四次普通攻击且位于冲刺距离的一半至全程内，才选择已冷却的地面冲刺；升空落地技按自身冷却且距玩家至少 120px 选用，不以半血为条件。冲刺、短跳和普通攻击的独立冷却分别为 5、3、0.75 秒。冲刺的原图动作、全身红色预警、红紫残影、中心爆发与双向焰浪沿用本项目素材和真实碰撞；参考曲线的位移段映射到已有生效窗口。第一关剑庭仍以独立召唤物运行，决策器按距离、上次攻击与子节点冷却选择横扫/突进；第三关只在中距离、冷却就绪且符合普通攻击次数或位置条件时突进。三关均由各自决策器返回招式意图，攻击状态处理完整动作。

## 职责边界

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| Boss 房 / 编排器 | 入口触发、真实边界和固定镜头、门与危险物启停、血条、战斗音乐、胜利通知 | 每一招的决策和伤害帧 |
| Main / Session | 核验胜利所属房间、玩家存活和唯一标记，发奖与 `user://` 存档，挑战模式隔离 | 攻击动画与物理位移 |
| Boss 本体 | 目标、生命、基础追击、身体碰撞、受击/死亡信号 | 房间门、存档和招式内的具体时序 |
| Decision | 按距离、高度、墙/边缘、上次攻击、冷却和持续威胁选下一招 | 修改 Hitbox、动画、位置或计时 |
| Attack State | 单招准备、生效、收招、位移、Hitbox 窗口、音画反馈、冷却 | 修改其他招式的内部计时 |

子节点向上发已发生事件的信号；不依赖跨场景绝对路径。配置 Resource 只读，运行时计时、锁向位置和已命中目标属于实例。物理位移只在 `_physics_process` 路径执行。状态机只在一招完成后接受下一次决策；死亡、玩家死亡、切房与重开必须清理攻击和持续威胁。招式冷却与全局追击间隔分开计算。

## 现有三关身份

- 第一关空谷守门者：本体横扫/突进与冷却招式剑庭并行。召唤结束立即恢复本体自由出招，七剑独立运行；不可等飞剑结束才恢复本体。
- 第二关炉心监守者：近战、突进、短跳和三连斩之外，保留升空、悬停蓄力、落地爆发与横向火墙。高空姿势、全身闪红、落点、焰浪可见段和真实伤害段须同步。
- 第三关缚钟守望者：横扫和突进后可选择双重回响或楼层共振，不按血量解锁。双重回响在施法期间记录最多两个相距足够远的落脚点，分身错峰攻击；相近落脚点合并为一次。第二处分身附近安全、远离玩家和本体时，Boss 可先显示换位虚影再换位，换位无伤害，随后固定收招。楼层共振在蓄力中锁定玩家脚下的地面或平台，只对该层造成一次伤害；换层可躲，不设钟锤打断。

## 验收

- 三关每招可追溯到选招条件、独立冷却、准备/生效/收招窗口和结束回调；冷却未好不能被首轮教学脚本绕开。
- 身体与武器走真实 Hurtbox 链路，同一次攻击去重，下一次独立攻击恢复判定；可见危险段与伤害范围、生命期一致。
- Boss 房开战前后镜头倍率不突变，战斗中出口不可用，击败后双向门与地图/出生点一致。环境修复标记不能替代击败标记；自动存档不回血。
- 每次共享战斗变更运行 `tools/check.ps1 -Full`；视觉变更加 `-Visual` 并实际看图。自动路线通过不等于真人难度与手感验收。
